# This account is no longer active

mixOmics development has moved to **[@mixOmics-org](https://github.com/mixOmics-org)**.

## Your existing links still work

Repositories were **transferred**, not deleted. GitHub redirects automatically:

- Web links to `github.com/mixOmicsTeam/<repo>` resolve to the new location
- `git clone`, `fetch` and `push` against the old remote continue to work
- Links in published papers and documentation remain valid

You do not need to do anything. Updating your remote is optional:

    git remote set-url origin https://github.com/mixOmics-org/mixOmics.git

## Where things are now

| | |
|---|---|
| The R package | [mixOmics-org/mixOmics](https://github.com/mixOmics-org/mixOmics) |
| Issues and bug reports | [mixOmics-org/mixOmics/issues](https://github.com/mixOmics-org/mixOmics/issues) |
| Usage questions | [mixomics-users.discourse.group](https://mixomics-users.discourse.group) |
| Documentation and tutorials | [mixomics.org](https://mixomics.org) |
| Install | `BiocManager::install("mixOmics")` — unchanged |

## Why

mixOmics is now maintained under an organisation rather than a personal account, so
that maintainer access, review, and long-term stewardship do not depend on one
individual's login.

This account is retained to preserve the `mixOmicsTeam` name and keep this notice in
place. It is not monitored — please do not open issues or send messages here.
